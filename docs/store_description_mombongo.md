# Mombongo - Description Store

## Nom de l'application
Mombongo

## Slogan
Votre caisse, vos stocks et vos ventes dans une seule application.

## Description courte (Google Play - 80 caracteres max)
Facturation, stocks et ventes pour vos points de vente en temps reel.

## Description longue
Mombongo est une application de gestion commerciale concue pour les commerces, boutiques et points de vente multisites.  
Elle permet de facturer rapidement, suivre les stocks, consulter les ventes et piloter la performance des equipes depuis une interface simple.

Avec Mombongo, vous pouvez:

- Encaisser vos ventes avec un module de facturation fluide.
- Gérer les articles et les stocks (ajout, mise a jour, suivi des niveaux).
- Recevoir des alertes de stock critique pour anticiper les ruptures.
- Consulter le journal des ventes et les rapports de performance.
- Suivre les resultats par caissier, site et periode.
- Utiliser des profils differencies: Caissier, Gestionnaire et Administrateur.
- Choisir la devise de travail (Franc congolais CDF ou Dollar USD) pour la facturation et les calculs.
- Mettre a jour facilement le profil et le mot de passe utilisateur.

Mombongo est pensee pour aider les equipes terrain a travailler vite, avec des donnees fiables pour de meilleures decisions au quotidien.

## Public cible
